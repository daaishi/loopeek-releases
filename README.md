# loopeek

HAP / NotchLC などリアルタイム再生用コーデックの動画ファイルを、重いVJソフトやNotchを起動せずにサッと確認・変換するためのMac/Windows対応デスクトップアプリ。

このリポジトリはビルド済みバイナリ配布専用です(ソースコードは含みません)。[Releases](https://github.com/daaishi/loopeek-releases/releases) から最新版をダウンロードしてください。

## macOSでの起動について

このアプリはApple公証(notarization)を受けていません。初回起動時に「開発元が未確認のため開けません」と表示される場合は、Finderでアプリを右クリック(またはControl+クリック)→「開く」を選択し、表示されるダイアログで再度「開く」を押してください。

## Pro版ライセンス

HAP/NotchLCのプレビュー再生、動画変換、連番画像書き出しの解放には有料ライセンスキーが必要です。[dougu.gumroad.com/l/loopeek-pro](https://dougu.gumroad.com/l/loopeek-pro) から購入できます。
